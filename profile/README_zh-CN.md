## 关于 ZSvirt

ZSvirt 为计算、存储、网络、虚拟机生命周期管理、高可用、可观测性和基础设施自动化提供统一控制平面。

ZSvirt 面向私有云、企业虚拟化和 IaaS 场景，为基础设施运维者提供一个可以自由审查、自动化、扩展和掌控的开放平台。

## 核心优势

<table>
  <tr>
    <td width="33%" valign="top">
      <h3>统一的基础设施管理</h3>
      通过集中式管理和一致的 API，统一管理计算、网络、存储以及完整的虚拟机生命周期。
    </td>
    <td width="33%" valign="top">
      <h3>面向生产的可靠性</h3>
      通过异步执行、无状态服务和工作流回滚机制，让复杂的基础设施操作更加可预测、可恢复。
    </td>
    <td width="33%" valign="top">
      <h3>模块化架构</h3>
      通过插件化架构扩展资源类型、平台能力和外部集成，同时保持平台的开放性，避免厂商锁定。
    </td>
  </tr>
</table>

## 部署场景

<table>
  <tr>
    <td width="50%" valign="top">
      <h3>企业虚拟化</h3>
      通过统一的计算、网络和存储管理，为生产虚拟机提供高可用、迁移、备份、监控等企业级能力。
    </td>
    <td width="50%" valign="top">
      <h3>VMware 迁移</h3>
      将现有 VMware 工作负载迁移到开放的虚拟化平台，同时保留企业生产环境所需的关键运维能力。
      <br><br>
      <a href="https://zsvirt.io/vmware-alternative/">
        <strong>了解 VMware 迁移方案 &rarr;</strong>
      </a>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h3>私有云与 IaaS</h3>
      构建 API 驱动的云基础设施，统一管理计算、虚拟网络、存储、租户、权限、配额和自动化运维。
    </td>
    <td width="50%" valign="top">
      <h3>家庭实验室与技术评估</h3>
      从轻量环境开始，用于学习、测试、技术评估、集成验证和概念验证，并可按需求逐步扩展。
    </td>
  </tr>
</table>

## 参与贡献

ZSvirt 欢迎开发者、运维工程师、技术作者、测试人员、翻译贡献者以及所有对虚拟化感兴趣的用户参与社区建设。

你不需要是一名软件开发者，也可以通过多种方式为 ZSvirt 作出贡献：

- 贡献代码、集成组件和自动化测试
- 改进文档、教程和翻译
- 测试新版本并验证缺陷修复
- 提交可复现的软件缺陷
- 分享部署方案和迁移经验
- 帮助其他社区用户解答问题

请阅读 [贡献指南](https://github.com/zsvirt/zsvirt/blob/main/CONTRIBUTING.md)，了解如何开始参与 ZSvirt。
