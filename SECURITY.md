# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in ZSvirt, please report it responsibly.

Please do not open a public GitHub issue for security vulnerabilities.

Instead, contact us at:

zsvirt@zstack.io

If the security mailbox is not available, please contact:

zsvirt@zstack.io

## What to Include

Please include as much detail as possible:

- A description of the vulnerability
- Affected component or repository
- Affected version, if known
- Steps to reproduce
- Potential impact
- Any logs, screenshots, or proof-of-concept details

## Response

We will review security reports and follow up as soon as possible. We may contact you for additional information during the investigation.

## Scope

This policy applies to ZSvirt community repositories under the `ZSvirt` organization.
